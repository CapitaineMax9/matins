🔑 Connexion à GitHub

Comment créer ce jeton ?
  1. Ouvre github.com/settings/personal-access-tokens/new.
  2. Nom : « matins », expiration au choix.
  3. Repository access → Only select repositories → matins.
  4. Permissions → Contents : Read and write, et Actions : Read and write.
  5. Génère le jeton, copie-le et colle-le ici. Il reste uniquement dans ce navigateur.
